# Button

Pulsante per le azioni dell'utente, in tre livelli: principale, secondario e discreto. Il principale (fondo `accent`, testo `on-accent`) si usa una sola volta per schermata, per l'azione che l'utente fa più spesso, come «Approva». Il secondario (fondo `surface-2`, bordo `border-strong`) per le alternative, come «Rifiuta». Il discreto (testo `accent-text`, senza fondo) per azioni minori. Etichette brevi che dicono cosa succede, in Space Grotesk 14 px peso 500; raggio `radius-sm`; anello di focus `focus` da 2 px. Chi lo usa fornisce l'etichetta e l'azione.
