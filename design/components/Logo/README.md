# Logo

Il logo Botcave nelle sue versioni, con le regole d'uso. Usare i file SVG del gruppo Logo: versione light su fondi chiari, dark su fondi scuri. Area di rispetto minima: un pixel del segno per lato. Sotto i 96 px di larghezza si usa solo il segno. Chi lo usa fornisce solo il fondo, che deve essere `surface-0`, `nebbia`, bianco oppure `notte`.
