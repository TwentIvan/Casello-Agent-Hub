# Alfred, maggiordomo vocale — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alfred, pagina vocale della console di Casello che parla con Gemini Live e usa il centralino delle squadre, con decisioni a doppio passo, sessioni contate nei tetti di spesa.

**Architecture:** L'API crea per ogni conversazione una riga `alfred_sessions` e un token temporaneo Gemini con configurazione bloccata; il browser parla direttamente con Gemini via WebSocket e gira le chiamate degli strumenti a `POST /api/alfred/sessions/:id/tools/:name`, che riusa `lib/teams/centralino.ts`. Codice nuovo in `artifacts/api-server/src/lib/alfred/`, route in `src/routes/alfred.ts`, pagina in `artifacts/casello/src/pages/alfred.tsx`.

**Tech Stack:** Express 5, Drizzle/Postgres (PGlite nei test), OpenAPI + Orval, React/shadcn, Web Audio (AudioWorklet), WebSocket Gemini Live.

**Spec:** `docs/superpowers/specs/2026-11-05-casello-alfred-design.md`

## Global Constraints

- Italiano per commenti, messaggi d'errore e commit (`feat(casello): …`); identificatori in inglese.
- Messaggi d'errore fissi in italiano, mai il testo di Gemini né del DB; mai chiavi, token temporanei, codici o loro hash nei log.
- Tutte le route di Alfred solo con il login (`sessionOnly`): con un token personale 403.
- Chiamate a Gemini: 15 s, `redirect: "manual"` (un 3xx è un errore), base `process.env.GEMINI_NATIVE_BASE ?? "https://generativelanguage.googleapis.com/v1beta"` (la variabile serve solo ai test, ignorata con `NODE_ENV=production`).
- Token temporaneo: `uses: 1`, `expireTime` +30 min, `newSessionExpireTime` +1 min.
- Voci: `Kore` (default), `Charon`, `Aoede`, `Puck`, `Fenrir`, `Leda`, `Orus`, `Zephyr`.
- Conferme: codice di 6 cifre, hash SHA-256, scadenza 60 s, una volta sola.
- Limiti: `POST /alfred/sessions` 10/min per utente; `scrivi_al_capo` usa `consumeTeamMessage`; `conferma_decisione` usa `consumeActionDecision`.
- Sessione inattiva da 35 min → `closed`; controllo ogni 5 min; conferme scadute da oltre 1 h cancellate.
- Dopo ogni modifica a `openapi.yaml`: `pnpm --filter @workspace/api-spec run codegen` e commit dei generati.
- Schema: ogni modifica in `lib/db/src/schema/`, `docs/schema-casello.sql` e `docs/migrations/2026-11-alfred.sql` (additiva, idempotente).
- `pnpm run typecheck` verde prima di ogni commit. Console senza scorrimento orizzontale (375 px e 1280 px).

## Review Focus

- Modello o account eliminati a sessione aperta (`ai_model_id` null): `usage` non deve rompersi, costo null, la sessione resta chiudibile.
- Contatori di `usage` più bassi del salvato, negativi o non interi: mai all'indietro; non interi o negativi → 400.
- Due `prepara_decisione` di fila nella stessa sessione: vale solo l'ultima conferma, la precedente non si conferma più.
- Sessione chiusa da un altro dispositivo mentre la pagina chiama uno strumento: 404 «sessione non trovata» e la pagina dice «Alfred è stato aperto su un altro dispositivo».
- Nome del modello con o senza il prefisso `models/`: idoneità, verifica e token usano il nome senza prefisso.
